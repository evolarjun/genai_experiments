GenAI experiments
=================

This repository contains some GenAI experiments that might come in handy later. 

Nothing in here is meant to be used as anything other than an experiment. No warranties express or implied.

Directories

- `biosample_ast_tests` - Convert BioSample XML to tab-delimited format like the Pathogen Detection AST Browser
- `genbank_clean_fasta` - I had to submit a bunch of assemblies to GenBank and they had some QC problems scripts here fixed them
