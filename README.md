GenAI experiments
=================

This repository contains some GenAI experiments that might come in handy later. 

Nothing in here is meant to be used as anything other than an experiment. No warranties express or implied.

Directories

- `biosample_ast_tests` - Convert BioSample XML to tab-delimited format like the Pathogen Detection AST Browser
- `genbank_clean_fasta` - I had to submit a bunch of assemblies to GenBank and they had some QC problems scripts here fixed them
- `linkchecker` - Check sites for dead links
- `meeting_time` - Helper HTML page for me to visualize meeting times in different timezones
- `paper_downloader` - Python workflow for downloading papers (focused on PubMed-linked content). 
- `t2v` - A tab-delimited file viewer. This project is now superseded by [`evolarjun/dless`](https://github.com/evolarjun/dless).
- `tree_tools` - Perl utilities for phylogenetic tree analysis, currently including `tree_distance.pl` for distance-oriented tree computations.
